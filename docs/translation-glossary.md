# PortfoliFLOW Translation Glossary

This glossary defines the canonical English equivalent for German domain
terms that appeared in the codebase prior to Phase-6 Block 0 language
hygiene. Contributors must use the canonical English term consistently
across code, templates, and documentation.

## Project / Process Terms

| German                | English (canonical)        | Notes                                       |
|-----------------------|----------------------------|---------------------------------------------|
| Sub-Strang            | sub-stream                 | also: Strang → stream                       |
| Bereich               | area                       | top-level grouping of modules               |
| Stichtag              | as-of date                 | reference date for a snapshot               |

The Document is either a new upload or one of the case's attachments (a second passage from the same PDF needs no second upload) — exactly one. Without a passage the document itself is kept in the file (a `document` kept row; a page is dropped); with one the passage is kept where Keep in says, as a `document_excerpt` with its page and caption (the passage's first line when the caption is empty). No comment, no record entry (§9 retires the pin ceremony). On success the route re-renders The question (#cs-question, its documents list), the Threads block out of band (an excerpt shows at once) and, out of band, the facts with the attachments count and an empty composer slot. A refusal (the file gates and caps, the choice of document, the page, a thread gone since) re-renders this form into the slot carrying ``error`` and what was typed; the file input cannot survive a re-render, so a file is chosen again. The page is text with a numeric keyboard (ui-standards R10: no native number field), read on the server.

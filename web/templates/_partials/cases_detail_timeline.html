{# Case timeline (ADR-0107, C3a) — the append-only spine, oldest first. Every entry carries a timestamp (the Journal date+time idiom) and an actor chip: ``pm`` shows the resolved user name, ``shirley`` / ``system`` show their fixed labels (mirroring the mock's ``actor--{pm,shirley,system}`` styling). Per-kind bodies: opened — "Case opened" with the origin phrasing. The materiality-at-opening block lives in the origin embed, not repeated here. note — the note text (payload["text"]). decision_record — the structured decision / rationale block. These two payload keys are the rendering contract; C3b's composer writes them. closed — "Case closed" with the closing note (payload["closing_note"], written by C1's close()). The milestones of the one milestone path (P-CS-1b, rendered since P-CS-3c2, D-CS-B-73) read one line each (entry.text), with the hand-over's or the wait's note beneath it when there is one: decision_record (with payload.decision_id) — "Decision recorded: {chosen} — {rationale}"; without a decision_id the legacy two-key block above. handed_over — "Handed over to {name}". waiting_set — "Waiting until dd Mon YYYY". waiting_lifted — "Waiting lifted — by hand" / "— on the date" / "— woken by: {the waking system line's text}". system_line — the line's text verbatim (actor System, D-CS-B-20). A milestone with a frozen pair (entry.file_href) carries "File as {word}" in its head and, under the row, the slot the frozen file opens into (#cs-file-as-{entry.id}, cases_file_frozen.html). A milestone without a pair (a legacy case) shows no button. pin — a legacy pin (b031, read-only since P-CS-4a, D-CS-M-7): the curation comment, then its class body from _partials/cases_artifact.html — document, scenario snapshot, consultation or chart snapshot (ADR-0107 C3b–C6, ADR-0114), the one anatomy a kept row in the file renders too. The payload contracts are documented on ``web/routes/cases.py``. Any other kind or artifact — a seeded row of an unrendered kind — falls through to the calm generic fallback: the head row alone (kind label + actor + timestamp), payload untouched, so it never breaks the page. Closed cases render identically — reading is never gated (the actions and composers are gated on the open or waiting state, but they live in the head, not here; "File as …" reads and so opens on a closed case too). Context: entries — list of projected entry dicts, ascending (_project_timeline). timeline_oob — when true the root carries hx-swap-oob. Its one writer, the pin composer's out-of-band refresh, retired with P-CS-4a; the id and the flag stay until P-CS-6a's legacy sweep. #}

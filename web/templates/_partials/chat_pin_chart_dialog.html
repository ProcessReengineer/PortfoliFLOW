{# Chart pin dialog (ADR-0114) — the sibling of chat_pin_dialog.html, swapped into #chat-pin-dialog by a chart figure's "Pin to case…" affordance. The difference to the consultation dialog is exactly the difference between the artefact classes: a frozen figure has nothing to trim, so there is no excerpt textarea. The figure is identified by its stored caption and the form posts the sidecar ``artifact_id`` — never the spec. The server resolves the spec from its own store, which is what makes the pinned record trustworthy (transport by reference, ADR-0114 §2). A handle that no longer resolves — trimmed away, a new chat, a restart, a stale id — or a figure that was too large to archive shows the calm unavailable state and offers no pin. The picker is the tenant's open cases, newest first, preselected to the active brief's case; with none the dialog says so and links to Cases rather than offering a dead dropdown. Cancel clears the slot (the composer-cancel idiom: a GET with ?cancel=1 returns an empty body). On a gate failure the POST re-renders this same partial with an inline error, the picked case and the comment preserved.

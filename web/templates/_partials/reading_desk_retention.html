{# The Retention pane (ADR-0139 §5, RD-D-8, RD-D-17, D-RD-2-18; M-RD-1 lines 3602–3643): the owner sets an age, previews what a run would remove, confirms, and sees the runs so far. Returned by GET /api/reading-desk/retention (plain, or with ``years`` as the preview) and by POST /api/reading-desk/retention/run; swapped into #rd-retention. The tab, the pane and both routes exist for the owner only. States (``retention.state``): idle — the form and the past runs. preview — what a run would remove, then the danger button and *Keep* (ui-standards R7). The confirmation carries the previewed age, cutoff and count; the run refuses a preview that no longer holds. zero — nothing is older than the cutoff. No confirmation is offered: a run that matches nothing would still be recorded. done — a run removed readings; it heads the past runs. ``retention.error`` is a refusal — an age the route cannot use (400), a preview that is out of date (409); it stands first beneath the form. The CSRF token travels in the ``hx-headers`` of the Section root. Context: retention — dict: state, years (str, as typed), error (str | None), lead, sub, action (str; preview), cutoff (str), count (int), runs (list of dict: run, by, rule, cutoff, count). #}

A retention run removes every reading whose document is older than the age you set. The findings and notes of those readings are deleted; the entries stay in the Library as removed.

The document date counts; where a document has none, the day it was read. Nothing is removed before you confirm.

{# Scraper progress fragment — payload of each SSE ``progress`` event. Replaces the ``.scraper-progress`` block emitted by the run-mount fragment so the user sees in-place updates rather than appended lines. Two phases (web.routes.scraper._drive_run): reading — "Reading ", "File k of N · m:ss" (scraper.js ticks the elapsed time since this frame arrived), the bar, a hint that a long document takes minutes, and Cancel. finishing — every file is read and the readings are being written: "Finishing…", "N of N read", the bar full, no Cancel. The elapsed span is aria-hidden so the live region is not announced every second. Required context: phase — "reading" | "finishing" current — int — 1-based index of the file being read filename — str — the file being read done — int — files read so far total — int — total files in the run percent — int — ``done / total * 100`` (pre-computed) csrf_token — for the cancel button run_id — for the cancel URL #}

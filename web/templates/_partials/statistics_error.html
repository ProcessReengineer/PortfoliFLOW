{# FX-error state for the Statistics section. Rendered by web/routes/statistics.py when the ADR-0099 §4 conversion boundary raises MissingFxRateError — a foreign-currency position has no FX rate at or before a date its NAV history needs, and the system never defaults a rate to 1:1. Since ADR-0102 the Statistics return series are derived from the *converted* history, so an uncovered position stops the whole universe rather than silently mixing currencies. The exception message is passed through verbatim on purpose — MissingFxRateError is a PortfoliFlowError and therefore user-facing (web/errors.py). It names the currency and the date, which is exactly what the operator needs to extend the `FX rates` sheet. Context: error_type — exception class name. error_message — exception message. #}

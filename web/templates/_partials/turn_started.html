{# Returned by POST /chat/messages. Renders the user's message inline, adds an empty assistant bubble, and exposes the SSE endpoint via data-attributes so the chat.js handler can open a native ``EventSource`` against /chat/stream/. Native ``EventSource`` replaces the HTMX-SSE extension on this surface — see HTMX bug #2343 (whitespace trimming) and the post-completion 404 reconnect storm noted in the manual smoke test on 2026-05-13. Context: turn_id — UUID of the just-started turn. user_content — what the user typed. assistant_bubble_id — DOM id of the bubble to populate. timestamp — ISO timestamp of the user message. thumbnails — optional list of {src, alt} image data URIs attached to this turn (ADR-0075). is_voice — True when this turn began as a voice recording; emitted as ``data-pf-voice`` so chat.js speaks the reply on ``done`` (ADR-0076). Defaults to 0 for text turns and rehydration. #}

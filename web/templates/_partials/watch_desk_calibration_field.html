{# One calibration editor field (ADR-0116 §7). Included with `f` bound to a field dict from `_calibration_field`: name, label, value, customised, hint, error, placeholder, marker_off. The marker states **provenance**, not the value: the input always shows the effective figure, and "default" means only that no stored column overrides it. On a refused save the input reflects the attempted text while the marker keeps describing what is stored — which is nothing new, because the save was refused. An inheriting field (the family WARN group, ADR-0133 §3.4) is the one exception: its input shows the stored value or a blank, `placeholder` shows the inherited value, and `marker_off` reads "inherits" instead of "default". `placeholder` is rendered only when set. #}

{# "On watch" — the live monitor beneath the Briefing cards (ADR-0089, DC2; edit affordances per ADR-0116 §6). Two honesty rules are load-bearing here and must not be "tidied" away: * Every gauge runs 0 → ceiling with the WARN tick at that subject's WARN fraction of the ceiling. The *scale* is identical on every row — the scenario-comparison axis rule applied to utilisation — and the mark is never moved to flatter a row. Since ADR-0116 §3 the WARN fraction is per subject (a watchpoint overlay may override the tenant default), so the mark is per-subject **positioned** from `row.warn_threshold_pct`; it is still never *rescaled*, and the row it marks is classified against exactly that threshold. Never rescale per row; never move the mark away from the threshold in force. A breach clamps the rendered fill to 100% while the printed figures stay honest. * Irene's note is assembled in the route from live status + the subject's acknowledged watch-state + the tenant's effective Floor Config. The template renders the assembled string and nothing more — it never composes a claim of its own. The head makes no observation-time claim at all, so a tenant whose beat has never run reads no bogus "last seen" stamp. A third rule joins them with the mute affordance: a muted row stays **visible**, tagged, and counted in its group header, and its status keeps rendering live. Mute suppresses finding creation, never truth — so this template must never hide a row, grey out a figure, or drop a muted subject from a count. A group renders **closed** on first load. Its summary line is the decision surface — name, badges, muted count, subject count and the effective set — so it already carries what decides whether opening the body is worth it, and the calm-by-default posture the Watch Desk keeps toward the book applies to its own first screen too. Closed is not hidden: every row stays in the document, the header counts stay live, and a muted row is still visible, tagged and counted one click away. The honesty rules above are unaffected — this changes disclosure, not content. Class names are the mock's verbatim (decision-console-mockup-B-final-v3) so DC5 can lift the mock CSS cleanly. Context: monitor — coverage_available, groups, rss. #}
